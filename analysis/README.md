# Analysis

This repository contains the final analysis macros used to study the correlation between the average transverse momentum ⟨p<sub>T</sub>⟩ and charged-particle multiplicity N<sub>ch</sub> in p–Pb collision systems at √s<sub>NN</sub> = 5.02 and 8.16 TeV.

The data were collected by the CMS detector at the LHC.

The ⟨p<sub>T</sub>⟩–N<sub>ch</sub> correlation is further used to estimate the squared speed of sound c_s² as a function of the effective temperature T_eff, following the model proposed by Gardim et al.
